# Fotografías de referencia del catálogo

Actualizado: **26 de octubre de 2026**.

Hay **20 fotografías locales para los 24 productos** del catálogo académico (`100 %` de cobertura). Las dos laptops comparten `laptop.jpg`, los tres monitores comparten `monitor.png` y los dos módulos de memoria RAM DDR4 comparten `ram-ddr4.jpg`. Si algún producto carece de imagen en base de datos o si la descarga falla, el cliente Android muestra un marcador de posición cuidado.

Las imágenes muestran modelos reales como referencia visual de un catálogo académico ficticio. No acreditan marca, capacidad, especificaciones ni modelo exactos del producto. No se modificó su contenido: se descargaron miniaturas de Wikimedia Commons con las licencias indicadas. Las miniaturas están entre 54 KB y 446 KB y se sirven desde la API, sin depender de enlaces remotos.

## Contrato y verificación

- `manifest.json` contiene las 24 entradas y los campos acordados para la carga SQL. Las rutas válidas tienen la forma `/media/productos/archivo.jpg` o `.png`.
- `fuentes_wikimedia.json` conserva metadatos de autor, licencia, URL original, bytes y SHA-256 de las 20 descargas verificadas.
- Validación efectuada: Content-Type de imagen, firma binaria JPEG/PNG, límite inferior a 1 MiB por archivo y revisión visual individual de los 20 archivos. La torre (`desktop.jpg`), la mini PC (`mini-pc.jpg`) y el soporte de monitor (`soporte-monitor.jpg`) muestran entorno real de escritorio.
- Al agregar o sustituir imágenes, conservar autor y enlace de licencia. Para CC BY-SA, mantener la atribución y la licencia de la fotografía cuando se redistribuya o adapte.
